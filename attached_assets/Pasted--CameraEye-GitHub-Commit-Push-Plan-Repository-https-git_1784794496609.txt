## Environment Variables

```env
NEXT_PUBLIC_CAMERAEYE_SITE_URL=http://localhost:3000

NEXT_PUBLIC_SANITY_PROJECT_ID=
NEXT_PUBLIC_SANITY_DATASET=production
SANITY_API_READ_TOKEN=

CAMERAEYE_CONTACT_WEBHOOK_URL=
CAMERAEYE_REVALIDATE_SECRET=
```

실제 프레임워크 호환성을 위해 Sanity 표준 환경변수 이름은 유지하고, CameraEye 전용 값에는 `CAMERAEYE_` 접두사를 사용합니다.

